# Проверка и создание вопросов PDD Connecticut

## Вход

Работай с разрешённым набором вопросов. Для существующего задания укажи commit, ID в этой версии, тип, принадлежность к пулам и отпечаток записи. Сохрани точный оригинал вопроса, всех вариантов, ключа, объяснения и схемы. Для черновика укажи цель обучения, предполагаемый формат и статус предложения. Снимок и источники для прохода должны быть зафиксированы. Укажи файл и строку или точный указатель на запись в артефакте. Сверь расхождения перевода с оригиналом, если он доступен. Пиши по-русски, сохраняй английские термины, когда они помогают сверке.

Работай по действующим правилам PDD и AIW. Используй [справочник официальных источников](references/sources.md) для навигации. Для каждого вывода о правиле укажи конкретный раздел или страницу, название, URL, редакцию или дату вступления в силу, если доступна, дату проверки и краткое основание. При офлайн-проверке используй закреплённые выдержки, предоставленные координатором, с указанным происхождением и контекстом исключений. Без достаточного основания ставь UNKNOWN. При конфликте источников укажи оба и ставь UNRESOLVED.

## Порядок проверки

1. Восстанови ситуацию только из условия и схемы. Укажи участников, очередность действий, траектории, полосы, видимые знаки, разметку, сигналы и исключения, если они влияют на ответ. Отметь недостающие сведения, если они меняют решение.
2. Определи ответ независимо от сохранённого ключа, затем сравни. Для проверяемого независимого прохода ключ и объяснение исключаются из входа технически. Для каждого варианта объясни, при каких данных он верен или неверен. Для порядка, множественного выбора, чисел и сопоставления проверь все шаги, единицы и допустимые комбинации.
3. Проверь правовое основание для Коннектикута. Различай обязанность, исключение, рекомендацию DMV и безопасную практику. Учитывай применимую редакцию и область действия нормы. Вывод должен следовать из источника и из данного сценария. Сторонние сайты и ответы моделей могут помочь найти ссылку. Правовые утверждения подтверждай по применимому официальному источнику Connecticut. Ссылку с непроверенной доступностью или неполным контекстом явно отмечай.
4. Проверь естественность русского языка и логику условия. Предпочитай понятную дорожную лексику и ясную последовательность действий. Устраняй кальки, двусмысленные ссылки, лишние отрицания и подсказки в формулировке. При необходимости сохраняй английское обозначение знака или термина рядом с русским.
5. Проверь варианты ответа. Каждый неверный вариант должен отражать правдоподобную ошибку и быть опровержимым по тому же условию. Сверь сопоставимость длины, детализации и грамматики вариантов. Проверь, что варианты не перекрываются по смыслу и правильный ответ нельзя угадать по форме.
6. Проверь объяснение и схему. Объяснение должно назвать решающий факт и показать, как применить правило в похожей ситуации. Схема должна совпадать с текстом, ключом, направлениями, положением стоп-линий и знаков. Если визуальное доказательство недоступно, отрази это отдельно.
7. Предложи минимальную правку и перечисли её влияние на ключ, число правильных ответов, порядок, сложность, пулы и связанные карточки, когда применимо. Для нового вопроса сначала составь черновик по источнику и затем проверь его по тем же шагам.

## Независимая проверка

Пометь случай для отдельного решения при расхождении с ключом, нескольких обоснованных ответах, конфликте источников, спорной схеме или предложении поменять ключ. Запроси у координатора отдельный разрешённый проход с чистым контекстом. Передай условие, варианты, схему и тот же пакет источников. Сохраняемый ключ, объяснение и вывод первого прохода остаются у координатора до фиксации независимого ответа. Запиши согласие или расхождение и его причину. До разрешения случая выдай статус UNRESOLVED и предложение об исключении из пакета к выпуску, если случай затрагивает ключ или юридическую правильность.

## Результат

Одна строка на ID и отдельная карточка на существенную находку. Укажи исходный commit и отпечаток, версию методики, результат по каждому критерию, класс проблемы, существенность, достоверность, основания, предложение и точку продолжения. Классы охватывают правовую ошибку, неоднозначность, русский язык, логику, варианты, объяснение и схему. Применяй VERIFIED, UNVERIFIED, UNKNOWN или UNRESOLVED. Помечай отдельно проверенные случаи без находок и случаи с недостатком данных. За один разрешённый пакет верни один компактный отчёт. Независимый проход предназначен для конкретных спорных случаев. Сохраняй оригинал один раз в закреплённом входном артефакте, а в компактном отчёте ссылайся на него по ID и отпечатку.

В режиме аудита возвращай отчёт с предложениями. Изменение банка, утверждение новой редакции и выпуск выполняются по действующим допускам AIW. Предложения по изменению методики передавай через существующий Memory Delta с ссылкой на доказательство.
