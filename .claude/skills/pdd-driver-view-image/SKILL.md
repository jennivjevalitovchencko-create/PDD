# Картинка «вид из-за руля» для вопроса PDD

Стиль утвердила пользователь 08.11.2026: реалистичная 3D-сцена «как в симуляторе», камера на уровне глаз водителя, чуть выше и с лёгким наклоном вниз, чтобы были видны полосы и разметка; снизу — общая приборная полоса. Вид сверху (SVG-схема) остаётся для отдельных задач, где важна точная геометрия полос и стоп-линий.

## 1. Когда нужна картинка

Нужна, если по тексту трудно представить, кто откуда едет, где знаки, сигналы, разметка, полосы. Не нужна для вопросов-фактов (числа, сроки, документы). Решение записывай в карточку проверки темы.

## 2. Описание сцены (до генерации)

Составь по условию и ключу таблицу, без которой не начинай:
- **Мы:** полоса (номер слева направо), действие (стоим у стоп-линии / едем N миль/ч), поворотник.
- **Дорога:** тип перекрёстка или участка, число полос, разметка (жёлтая осевая — сплошная/прерывистая/двойная, белые линии, стрелки на асфальте, стоп-линия, переходы).
- **Регулирование:** светофор (какой сигнал, есть ли стрелка), знаки (STOP, YIELD, NO TURN ON RED…), полицейский, школьный автобус и т.п.
- **Участники:** каждая машина / пешеход / велосипедист — откуда, в какой полосе, куда едет, насколько близко. Всё, что важно для ответа, должно быть крупно и полностью видно.
- **Чего не должно быть:** лишние знаки, светофоры, люди, надписи, логотипы, номера.
- **Зеркала:** заполнять, только если в вопросе важно, кто сзади/сбоку (иначе — пустое серое стекло).

Реалии США/Коннектикута: правостороннее движение; осевая жёлтая; краевые и разделительные линии белые; знаки MUTCD; мили в час.

## 3. Генерация в Canva

`generate-image`, `aspectRatio: LANDSCAPE_16_9`. Подсказка по-английски, по шаблону:

> 3D driving simulator style render, camera slightly higher than a normal driver's eye height and tilted a little down, so the road surface and all lane markings in front are clearly visible; no car interior visible. Daytime, [suburban/town] Connecticut, USA. [Сцена из п.2 — дорога, разметка, регулирование.] [Участники — каждый с полосой, направлением и словами «large/fully visible».] Sidewalks, curbs, houses and trees at the corners. No text, no letters, no logos[, no pedestrians].

Не загружай в генератор скриншоты чужих приложений (например, немецких тестов) — только описание словами. Ориентир по устройству кадра есть в описании выше.

Опрос задания: `get-generate-image-job` (в ответе только превью ~200 px и `media id`).

## 4. Полный размер

Превью и `get-assets` дают только подписанные миниатюры 200 px. Полный размер:
1. Рабочий дизайн в Canva пользователя: **«PDD — картинки к вопросам»** (дизайн в Canva пользователя; ID хранится в приватной памяти, не в репозитории) (презентация 1920×1080; страница 3 — приборная панель).
2. `read-design` с `open_transaction: true` → `edit-design` `add_page` (1920×1080, title = ID вопроса) → `read-design` (page_indices) за id страницы → `edit-design` `insert_fill` (asset = media id, left 0, top 0, 1920×1080) → сверить миниатюру → `finalize: commit` (пользователь разрешила сохранять в этот рабочий дизайн 08.11.2026).
3. `export-design` `{type: "jpg", quality: 90, pages: [N], width: 1600}` → `curl` по ссылке экспорта (ссылка временная) в папку черновиков, не в банк.

## 5. Кадр «как в машине»

Утверждено 08.11.2026 (после нескольких правок пользователя): современная изогнутая панель (старая «прямая» отклонена); рамок сверху и по бокам нет — сцена во всю ширину под тонкой тёмной полосой крыши; крупное зеркало заднего вида висит на этой полосе и не закрывает светофоры; верх щитка над панелью — плавная низкая дуга; боковые зеркала — широкие, как настоящие наружные зеркала: внутренняя сторона высокая, верхний край опускается к наружной стороне, наружный верхний угол сильно скруглён, по краям чёрной полосы панели (свои векторные формы; стёкла внутри приборного блока затемнены); зеркало заднего вида — крупный скруглённый прямоугольник (≈660×190 из 1600, выше по просьбе пользователя 08.11), на ножке; верхняя тёмная полоса тонкая (sy≈56), зеркало заходит на небо; если закрывает светофор или знак — опустить сцену для этой картинки (до sy≈122) или перегенерировать; проверять на каждой картинке. Форма зеркал — по силуэту из примеров пользователя, без копирования чужой графики. Готовая сборка — `assets/compose-sample.html`, функция `frame(scene,speed,left,right)`: один SVG; сцена 1600×900 на y=40 почти во всю ширину (тонкие стойки — пользователь попросила большое стекло 08.11.2026); панель `assets/dashboard-modern-1600x800.jpg` (Canva, без стрелки, поворотники серые, зеркала пустые) уменьшена до 0,66 и стоит по центру, фон вокруг неё чисто чёрный (как в JPG), верхний край приборного щитка — кривая с подъёмом к центру. Координаты ниже умножать на 0,66 и сдвигать на отступ панели (см. код).
- координаты панели заданы в масштабе миниатюры 600×300 (×2.667): центр спидометра (299,150), длина стрелки 58; угол = 133° + скорость/80 × 274° (0 — слева внизу, 40 — вверху, 80 — справа внизу);
- по бокам спидометра — свои крупные значки (функция panel): большая стрелка поворотника в центре (зелёная #35e06a, если включён, иначе серая) и по два значка сверху и снизу (стандартные символы ISO 2575, нарисованы самостоятельно: дальний свет, ремень, (ABS), тормоз (!) / ближний свет, скользкая дорога (ESP), двигатель, давление шин; в коде цвет — метка CLR, не «C», иначе ломаются кривые); мелкие значки исходной панели закрыты — 08.11.2026, по образцу размера из примера пользователя
- поворотник задаётся параметрами left/right функции frame
- зеркало заднего вида не должно закрывать светофоры и знаки сцены — при необходимости сдвинуть или убрать;
- боковые зеркала (стёкла по краям панели) заполнять отдельной картинкой, только когда важно, кто сзади/сбоку.

Скорость и поворотник берутся из условия (стоим — 0).

## 6. Проверка (обязательно)

Сверь картинку с условием и ключом по таблице п.2: каждая позиция, полоса, направление, сигнал, знак, разметка. Отдельно: нет ли того, что меняет ответ (лишний знак STOP, второй пешеход, стрелка светофора). При расхождении — новая генерация с уточнённой подсказкой; не «объясняй» картинку текстом. Затем независимый взгляд `pdd-question-reviewer` (ему — условие, варианты, ключ и картинку). Покажи пользователю до встраивания.

## 7. Встраивание (только с разрешения на выпуск)

- Сжать сцену до ~960 px по ширине, JPG ~70–100 КБ; хранить исходник в `editorial/img/` (вне банка), в `index.html` — data URI.
- Приборную полосу хранить в приложении один раз; у вопроса — поля сцены и `dash` (скорость, поворотники).
- Текст условия при этом обычно меняется → прогресс вопроса сбрасывается (`QV` в `index.html`, дата изменения).
- Тест `tests/integrity.cjs`: картинка есть, совпадает с файлом в `editorial/img/`, параметры `dash` заданы.

## 8. Текст вопроса при картинке (пользователь, 09.11.2026)

Если у вопроса есть картинка, в приложении — картинка и **короткий текст** («Вы поворачиваете налево. Кому вы обязаны уступить?»). Всё, что видно на картинке (сигнал, полосы, участники, поворотник, скорость, зеркала), в текст не повторять. Полное описание ситуации хранить для редакторов: `editorial/img/driver-view/question-texts.json` (short / full / picture); тест сверяет короткий текст.

Ориентиры по стилю (немецкий тест на русском, скриншоты пользователя — только образец, графику не копировать):
- общий вопрос «Как вы поступите?», «К чему нужно быть готовым?», «Что нужно иметь в виду?»; ответ решают детали картинки — знак, разметка, кто в зеркалах, погода;
- короткие варианты от первого лица («Я сбавлю скорость», «Я готов(а) затормозить»), несколько верных;
- зеркала всегда показывают настоящий вид назад (пустые серые стёкла выглядят как заглушка — замечание 27);
- значки панели показывают состояние: например, включённый ближний свет горит зелёным ночью и в дождь;
- погоду показывать на стекле: капли, дворники, снег у обочины.
